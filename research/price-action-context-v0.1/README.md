## 核心内容

识别趋势/震荡、结构低高点、支撑/阻力、三点确认趋势线与上升楔形；识别 Pin Bar、吞没线、内包线、Doji；依据关键位置过滤信号。按照两种入场（破极值、50%–61.8%回撤）各自计算止损、下一有效支撑/阻力和毛盈亏比，并过滤不足 1:2 的计划。持仓回放处理结构失效撤销、反向吞没退出、可选 1R 保本、同根事件先后不明和跳空。

